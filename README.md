# fountain-pen-ink-cartridge-dispenser

So this is a cartridge holder that lets u fill it up with ink cartridges, and when u need to  change the ink, you can push one out and then replace it so this will be on ur tabel; this is especially important if u use a fountain pen like me, so u can work more efficiently

I made this because I was constantly getting tired of digging through my drawer for the box of cartridges. So I thought, what if I just put it on the desk in, like, a stand/holder.
